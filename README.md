## ¿Qué es Rur-uReplay?

**Rur-uReplay** es una app de Android enfocada en grabar la pantalla de forma ligera. Conteniendo todo lo básico de un grabador de pantalla.

La interfaz moderna utiliza un estilo de anime, aunque puede ser personalizada.

<p align="center">
  <img src="https://bocchi.rocks/omnibus/assets/img/page/character/ikuyo/image_movienew.png" width="280" alt="Ikuyo Kita">
</p>

## Funciones

- Grabación de pantalla.
- Capturas de pantalla.
- Biblioteca para revisar el contenido guardado.
- Edición rápida (y basica) del contenido disponible.
- Ajustes y preferencias.
- Auto-update checker
- Interfaz personalizable

##  Cómo usarla

1. Instala la APK desde el botón de descarga.
2. Abre Rur-uReplay y entra en **Grabar pantalla**.
3. Concede los permisos que Android solicite.
4. Inicia la grabación.
5. Revisa tus archivos desde **Biblioteca** o **Capturas**.
6. Usa el editor cuando necesites hacer algunos ajustes rápidos (aún está en mejora).
